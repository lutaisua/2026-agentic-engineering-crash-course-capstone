## Scope and exclusions

Implemented: local non-secret profiles, versioned configuration, input validation,
explicit publisher selection, context isolation keys, safe configuration writes,
offline CLI commands, verifier, and user documentation. This establishes FR-01/02
and foundations for later authentication/reporting requirements.

No authentication, protected credential/token values, Microsoft report catalog,
network connector, export, or live entitlement was implemented or verified here.
Credential references are descriptions only; availability is not checked offline.
There are no skipped live tests counted toward this milestone. Later versions
require their own authorized acceptance gates.
